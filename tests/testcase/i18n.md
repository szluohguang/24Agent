# i18n — 界面国际化黑盒测试

## 概述

用户在界面中切换中/英文，所有 UI 文本实时更新为对应语言。中英文翻译完整一致，无遗漏或不匹配。

## 测试用例

### 操作 1: 切换到中文界面

- **页面状态**: 当前界面语言为英文，控制栏显示 "Permission: Safe"、"Create Task"、"Connected" 等英文标签
- **用户操作**: 在控制栏或设置中找到语言切换按钮，点击切换到"中文"
- **预期结果**:
  - 控制栏文字变为"权限: Safe"、"创建任务"、"已连接"
  - 任务树中 "No tasks" 变为"暂无任务"
  - StreamConsole 中 "No active session" 变为"无活动会话"
  - 时间线面板标题 "Timeline" 变为"时间线"
  - 设置弹窗中各标签页标题切换为中文
  - 所有 UI 文本（按钮、标签、提示信息）均切换为中文

### 操作 2: 切换到英文界面

- **页面状态**: 当前界面语言为中文
- **用户操作**: 点击语言切换按钮切换到"English"
- **预期结果**:
  - 所有 UI 文本从中文变回英文
  - 各面板标签、按钮文字、提示信息均为英文
  - 与操作 1 中英文状态一致

### 操作 3: 语言设置持久化

- **页面状态**: 当前语言为中文
- **用户操作**: 刷新页面（F5）
- **预期结果**:
  - 页面重新加载后仍显示中文界面
  - 语言偏好被持久化保存

### 操作 4: 语言切换后创建任务

- **页面状态**: 当前语言为中文，界面文字均为中文
- **用户操作**: 创建一个任务，等待任务完成
- **预期结果**:
  - 创建的任务描述为中文，正常显示
  - 时间线中事件描述为中文（"任务已添加: xxx"）
  - 任务完成时的提示信息为中文
  - 任务失败时的错误信息为中文
