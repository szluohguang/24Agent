# system-overview — 系统概览黑盒测试

## 概述

系统概览面板（可能嵌入控制栏或设置弹窗中）以指标卡片形式展示系统整体运行状态。

## 测试用例

### 操作 1: 指标卡片展示

- **页面状态**: 系统运行中，有多个任务
- **用户操作**: 观察系统概览区域
- **预期结果**:
  - 显示任务总数（总创建任务数）
  - 显示运行中的任务数
  - 显示活跃 Agent 数
  - 显示预算使用情况：已花费 / 总限额（如 "$5.00 / $50.00"）
  - 显示当前权限级别
  - 显示当前并行度设置

### 操作 2: 指标实时更新

- **页面状态**: 系统概览打开，正在观察指标
- **用户操作**: 创建一个新任务，再等待它完成
- **预期结果**:
  - 创建任务后：任务总数 +1
  - 分发任务后：运行中任务数 +1，活跃 Agent 数 +1
  - 任务完成后：运行中任务数 -1，活跃 Agent 数 -1
  - 预算使用随任务执行增加
  - 所有数字实时更新，不需手动刷新

### 操作 3: 空状态指标

- **页面状态**: 系统刚启动，无任何任务
- **用户操作**: 观察系统概览
- **预期结果**:
  - 任务总数 = 0
  - 运行中任务数 = 0
  - 活跃 Agent 数 = 0
  - 预算花费 = 0，限额显示默认值 50
  - 权限级别显示默认值 safe
