# timeline — 时间线面板黑盒测试

## 概述

右侧/底部时间线面板展示系统所有重要事件的时间序列表，包括任务创建、分发、完成、工具调用、Shell 执行等。

## 测试用例

### 操作 1: 事件列表展示

- **页面状态**: 系统中有多个任务经历过不同阶段
- **用户操作**: 观察时间线面板
- **预期结果**:
  - 按时间顺序（倒序或正序）列出所有事件
  - 每个事件包含：时间戳、事件类型、描述文字
  - 不同事件类型有对应的图标（系统事件、任务事件、工具调用、Shell 执行等）

### 操作 2: 事件类型覆盖

- **页面状态**: 完成一次完整的任务生命周期
- **用户操作**: 创建任务 → 分发 → 等待完成（或失败）
- **预期结果**:
  - 时间线出现以下事件：
    - "Orchestrator started"（系统启动）
    - "Task added: xxx"（任务创建）
    - "Task dispatched"（任务分发）
    - "Tool: bash"（工具调用）
    - "$ npm test"（Shell 命令）
    - "Task completed" / "Task failed"（任务完成/失败）

### 操作 3: 事件数量增长

- **页面状态**: 当前时间线有若干条事件
- **用户操作**: 创建并分发一个新任务
- **预期结果**:
  - 时间线自动增加新事件
  - 新增的事件出现在列表顶部（倒序）或底部（正序）
  - 无需手动刷新即可看到新事件

### 操作 4: 空状态

- **页面状态**: 系统刚启动，尚无任何操作
- **用户操作**: 打开页面
- **预期结果**:
  - 时间线面板显示空状态提示："暂无事件" 或 "No events"
  - 可能显示 "Orchestrator started" 启动事件
