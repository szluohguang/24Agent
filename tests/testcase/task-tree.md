# task-tree — 任务树面板黑盒测试

## 概述

左侧任务树面板展示所有任务的层级关系。用户通过它查看任务列表、状态、依赖关系和执行操作。

## 测试用例

### 操作 1: 任务节点展示

- **页面状态**: 任务树中有多个任务
- **用户操作**: 观察任务树面板
- **预期结果**:
  - 每个任务显示为一行节点
  - 节点显示任务描述文字
  - 节点显示状态标签（pending / running / completed / failed / awaiting_review）
  - 各状态有对应的颜色标识（pending=灰色, running=蓝色, completed=绿色, failed=红色, awaiting_review=橙色）
  - 每个节点旁有对应的操作按钮（Dispatch / Abort / Delete 等）

### 操作 2: 节点选中高亮

- **页面状态**: 任务树中有多个任务
- **用户操作**: 点击某个任务节点
- **预期结果**:
  - 被点击的节点背景高亮（与其他节点区分）
  - StreamConsole 可能切换显示该任务的输出（如果有）
  - 再次点击另一个节点，高亮转移到新节点
  - 点击空白处，取消选中

### 操作 3: 依赖关系可视化

- **页面状态**: 任务 B 依赖任务 A，任务 C 依赖任务 B
- **用户操作**: 观察任务树
- **预期结果**:
  - 任务 B 显示依赖标记（如缩进、箭头或"Depends on: A"文字）
  - 任务 C 显示依赖任务 B
  - 依赖关系的层级关系清晰可见
  - 鼠标悬停时可能显示更多依赖详情

### 操作 4: 空状态

- **页面状态**: 系统无任何任务
- **用户操作**: 打开或刷新页面
- **预期结果**:
  - 任务树面板显示空状态提示："暂无任务" 或 "No tasks"
  - 面板中无任何节点
  - 可能显示创建任务的引导提示

### 操作 5: 大量任务滚动

- **页面状态**: 创建了 20+ 个任务
- **用户操作**: 滚动任务树面板
- **预期结果**:
  - 面板内容可滚动
  - 所有任务节点正常显示
  - 无卡顿或渲染异常
  - 选中和操作按钮功能正常
