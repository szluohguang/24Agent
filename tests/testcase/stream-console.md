# stream-console — 流式控制台黑盒测试

## 概述

中间面板展示任务运行时的实时流式输出，包含 Agent 的思考过程、工具调用、Shell 命令执行等。

## 测试用例

### 操作 1: 流式文本展示

- **页面状态**: 任务正在运行，StreamConsole 面板清空
- **用户操作**: 观察面板（无需操作）
- **预期结果**:
  - 面板逐字/逐段追加输出内容
  - 输出实时更新，无需手动刷新
  - 内容从顶部持续追加到底部
  - 面板自动滚动到最新内容

### 操作 2: 不同类型内容颜色区分

- **页面状态**: Agent 正在执行任务，产生多种类型的输出
- **用户操作**: 观察 StreamConsole 中不同内容的颜色
- **预期结果**:
  - Agent 文本回复（thinking）：一种颜色（如白色/青色）
  - Shell 命令执行：另一种颜色（如绿色，带 `$` 前缀）
  - 工具调用：第三种颜色（如黄色或紫色）
  - 不同类型之间有明显的视觉区分

### 操作 3: 自动滚动行为

- **页面状态**: StreamConsole 有多行输出，已滚动到中间位置
- **用户操作**: 等待新内容到达
- **预期结果**:
  - 默认情况下面板自动滚动到底部
  - 如果用户手动向上滚动查看历史内容，自动滚动暂停
  - 用户点击面板底部"滚动到底部"按钮后恢复自动滚动

### 操作 4: 空状态

- **页面状态**: 无活动会话，或没有任务在运行
- **用户操作**: 打开或刷新页面
- **预期结果**:
  - StreamConsole 面板显示空状态提示："无活动会话" 或 "No active session"
  - 面板内无任何输出内容

### 操作 5: 切换任务时内容切换

- **页面状态**: 有两个任务 A 和 B，A 已运行完成有输出内容，B 正在运行
- **用户操作**: 在任务树中点击任务 A，再点击任务 B
- **预期结果**:
  - 点击 A 时，StreamConsole 显示 A 的历史输出
  - 点击 B 时，StreamConsole 切换到 B 的实时输出（或显示 B 已有输出）
  - 切换时面板内容正确更新
