# settings-dialog — 设置弹窗黑盒测试

## 概述

设置弹窗是用户进行系统管理和查看信息的中心入口，包含多个标签页（Health / Schedule / History / Webhook）。

## 测试用例

### 操作 1: 打开和关闭设置弹窗

- **页面状态**: 页面加载完成，右上角或控制栏有"设置"图标按钮
- **用户操作**: 点击"设置"按钮
- **预期结果**:
  - 弹窗打开，覆盖在主内容之上
  - 弹窗有标题"设置" 或 "Settings"
  - 弹窗有关闭按钮（X）或点击外部关闭
  - 点击关闭按钮或蒙层区域，弹窗关闭

### 操作 2: 标签页切换

- **页面状态**: 设置弹窗打开，默认显示某个标签页
- **用户操作**: 依次点击 Health / Schedule / History / Webhook 标签
- **预期结果**:
  - 每次点击后标签页内容切换
  - 当前选中的标签高亮显示
  - 各标签页内容正确：
    - Health: Agent 列表和健康状态
    - Schedule: 定时任务列表和管理表单
    - History: 历史时间线
    - Webhook: Webhook 配置列表和表单

### 操作 3: 设置弹窗中配置修改

- **页面状态**: 设置弹窗的某个标签页中有配置项（如 Schedule 或 Webhook）
- **用户操作**: 添加/修改配置，点击保存
- **预期结果**:
  - 配置保存成功
  - 关闭弹窗后重新打开，修改的配置仍然存在
  - 配置修改立即生效

### 操作 4: 弹窗中显示实时数据

- **页面状态**: 设置弹窗打开，显示 Health Dashboard
- **用户操作**: 切换到其他页面再切换回来，或在弹窗打开时后台有任务变化
- **预期结果**:
  - Health Dashboard 中的 Agent 信息实时更新
  - 无需关闭重开即可看到最新数据
  - Schedule 列表也是最新状态
